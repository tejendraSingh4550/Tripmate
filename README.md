# TripMate

A responsive travel dashboard concept for organizing trips, exploring destinations, and keeping travel plans in one place.

## Run it

No installation or build step is required. Open `index.html` in a modern browser, or serve this folder with any static file server.

## Features

- Responsive travel dashboard layout
- Trip calendar with sample upcoming trips
- Destination and past-trip cards
- Europe map panel with travel stats and zoom controls
- New-trip form
- Navigation and small interactive controls

## Project files

- `index.html` — page structure and sample dashboard content
- `styles.css` — layout, styling, and responsive breakpoints
- `app.js` — dialog and dashboard interactions

## Notes

The dashboard currently uses sample travel data. Photos and fonts load from Unsplash and Google Fonts, so those assets require an internet connection.
